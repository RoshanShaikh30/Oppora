# Oppora

## Problem

Students miss hackathons, competitions, and opportunities because information is scattered across multiple websites.

## Solution

Oppora aggregates opportunities from public websites using adaptive self-healing web scrapers built with Bright Data Scraper Studio.

## Core Features

- Opportunity aggregation
- Structured JSON output
- Dashboard
- Self-healing scraper workflow
- Scraper health monitoring

## Target Sources

- Devfolio
- MLH
- Additional public opportunity source

## Hackathon Goal

Demonstrate a scraper that continues working even when website structures change.
